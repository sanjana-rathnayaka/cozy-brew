# ☕ Cozy Brew Cafe Website

This is a simple, responsive landing page created for a Coffee Shop named "Cozy Brew". 
It allows customers to view the menu and details about the shop on their mobile devices.

## 🔗 Live Demo
View the live website here: https://cozy-brew-self.vercel.app/

## 🛠️ Technologies Used
* HTML5
* CSS3 (Flexbox & Grid)
* Responsive Design

## 📂 Project Structure
* `index.html` - The main structure of the page.
* `style.css` - Styling and layout.
* `/images` - Contains all assets.
